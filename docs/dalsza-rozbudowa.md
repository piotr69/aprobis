# Dalsza Rozbudowa

- Integracja z Microsoft Entra ID i SSO.
- Przechowywanie plików w SharePoint, Azure Blob albo S3.
- OCR i automatyczne uzupełnianie metadanych faktur.
- Podpis elektroniczny i pieczęć kwalifikowana.
- Edytor graficzny workflow z walidacją warunków.
- Automatyczna eskalacja zaległych zadań (przypomnienia w aplikacji i maile o nowych zadaniach już działają).
- Kursy walut w regułach kwotowych.
- Import struktury organizacyjnej z HR albo Active Directory.
- Zaawansowane raporty SLA, czasów akceptacji i wąskich gardeł.
- Rejestr spraw/kancelaryjny z numeracją zależną od typu dokumentu.
- Polityki retencji i automatyczna archiwizacja.
